# 文件管理手动测试包

这些文件全部用于测试。请在软件里操作；迁移后测试包布局会变化。需要从头重测时，可只清理本目录下生成的 `01_` 至 `06_` 文件夹，再运行 `python 生成测试文件.py`。生成脚本不会覆盖不同内容的已有文件。

| 场景 | 测试位置 | 检查点 |
| --- | --- | --- |
| 原位整理 | `01_原位整理/下载区` | 按类型、月份、类型／月份预览。默认只处理当前层级；已有的 `图片/封面.PNG` 不应被覆盖，新文件应编号。 |
| 跳过与兜底 | 同一下载区 | `.隐藏文件.txt`、`.part`、`.tmp`、`.crdownload` 及子文件夹应跳过；`.xyz` 和无扩展名应进入兜底分类。 |
| 扩展名筛选 | 同一下载区 | 填 `pdf,png` 后仅预览这两类，再清空筛选。 |
| 托管已有文件夹 | `03_托管目标/工作资料` | 拖入「新增托管」窗口，自动填写路径和名称；原文件仍在。可把 `学习资料` 设为第二个托管目标。 |
| 批量／递归迁移 | `02_托管迁移/来源_甲`、`来源_乙` | 比较是否勾选子文件夹的预览；两份 `公共说明.pdf`、两份 `同名记录.txt` 应编号；源目录保留。 |
| 单文件与待分类区 | `04_单文件导入` | 多选、混合拖入、重复导入路径，检查去重；移出、清空待分类区不应删除原文件。 |
| 自定义规则 | `05_自定义规则` | 文件名关键词设「合同」「发票」；月份设 `2025-04`、`2026-09`；扩展名设 `jpg,png` 和 `pdf`，检查大小写与未匹配目录。 |
| 预览、排除、撤销 | 任一来源 | 未确认迁移时源文件仍在；排除预览项；迁移后从操作记录撤销并检查恢复位置。 |
| 安全边界 | `06_安全与撤销` | 对第一个文件预览后修改再确认，应跳过；迁移第二个后在原处新建同名文件再撤销，应保留两份；迁移第三个后修改目标文件再撤销，应报告未恢复。 |

注意：`图片/封面.PNG` 和托管目标中的 `文档/公共说明.pdf` 是刻意放置的同名占位文件，不是有效媒体／文档，专用于验证不会覆盖。`大写图片.JPG` 是扩展名样例，也不是真实 JPEG；其余 PDF、PNG、WAV、ZIP、CSV 是可读取的真实格式。跨磁盘迁移需要你自行把某个来源文件夹复制到另一磁盘测试，此包只在当前项目中生成文件。
